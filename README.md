# <br> 🐍 Python Development Tasks
## ✅ Task 1: Simple Calculator

***A command-line calculator that performs basic arithmetic operations.***

### Features:

- **Addition, Subtraction, Multiplication, Division**
- **User input-based execution**
- **Simple CLI interface**

## ✅ Task 2: Contact Book (GUI Application)

***A desktop application built using Tkinter & CustomTkinter for managing contacts.***

### Features:

- **Add, update, delete contacts (CRUD)**
- **Search functionality**
- **Graphical user interface**
- **Data storage support**

## 🔐 Task 3: Password Generator (Secure CLI Tool)

***A secure password generator built using Python’s secrets module.***

### Features:

- **User-defined password length**
- **Cryptographically secure generation**
- **Includes letters, numbers, and symbols**
- **Lightweight CLI tool**

## ✅ Task 4: Rock Paper Scissors Game

***An interactive GUI-based game with score tracking and history.***

### Features:

- **Score tracking**
- **Match history log**
- **CustomTkinter-based UI**

# <br> 📊 Data Science & Machine Learning Tasks

## 🌸 Task 1: Iris Flower Classification

**A classification model to predict iris flower species based on features.**

### Models Used:

- **K-Nearest Neighbors (KNN)**
- **Logistic Regression**
- **Support Vector Machine (SVM)**

***Goal:*** **```Classify iris flowers into species based on sepal and petal measurements.```**

## 🎬 Task 2: Movie Rating Prediction

**A regression-based machine learning model to predict movie ratings.**

### Models Used:

- **Linear Regression**
- **Random Forest**
- **XGBoost**

***Goal:*** **```Predict movie ratings based on relevant features.```**

## 🚢 Task 3: Titanic Survival Prediction

**A classification model to predict passenger survival on the Titanic dataset.**

### Models Used:

- **Logistic Regression**
- **K-Nearest Neighbors (KNN)**
- **Naive Bayes (NB)**
- **Decision Tree**
- **Support Vector Machine (SVM)**

***🏆 Best Performing Model: SVM (Highest Accuracy)***

***Goal:***
**```Predict survival chances based on passenger data.```**
