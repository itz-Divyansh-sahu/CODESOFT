# 🔐 Password Generator

### A secure command-line Password Generator built with Python that creates strong, random passwords based on a user-defined length. The project uses Python's built-in ```secrets``` module to generate cryptographically secure passwords suitable for security-sensitive applications.

# 📖 Overview

*This application allows users to generate random passwords by specifying the desired password length. The generated passwords include a mix of uppercase letters, lowercase letters, digits, and special characters to improve security.*

# <br> ✨ Features
- **🔢 User-defined password length**
- **🔒 Cryptographically secure password generation using the secrets module**
- **🔤 Uppercase and lowercase letters**
- **🔢 Numbers**
- **✨ Special characters**
- **⚡ Fast and lightweight command-line application**
- **🛡️ Generates strong, random passwords**
