# ✊📄✂️ Rock Paper Scissors Game
### A fun and interactive Rock Paper Scissors game built with Python and Tkinter. The application features a user-friendly graphical interface, real-time score tracking, and a game history log to keep track of every match played.

# <br> 📖 Overview

*This project recreates the classic Rock Paper Scissors game in a desktop application. Players compete against the computer by selecting Rock, Paper, or Scissors. The application instantly determines the winner, updates the scoreboard, and records each round in the game history.*

# <br>✨ Features
- ***🎮 Interactive graphical user interface (GUI)***
- ***✊ Rock, 📄 Paper, and ✂️ Scissors choices***
- ***🤖 Computer-generated random moves***
- ***🏆 Automatic winner detection***
- ***📊 Live score tracking***
- ***📜 Match history with previous game results***
- ***🔄 Play multiple rounds without restarting***
- ***🖥️ Clean and responsive interface***

# <br> 🛠️ Technologies Used
- **Python 3**
- **Tkinter**
- **CustomTkinter**
- **Random module**

# <br>🎯 How to Play
1. Launch the application.
1. Select number of rounds from Home page
2. Click 'Next' to start the game
3. Choose Rock, Paper, or Scissors in each round
4. Comp will automatically make its move
5. Result and score will update instantly
6. After all rounds, final winner will be shown
7. You can view match history anytime
