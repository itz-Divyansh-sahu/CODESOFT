# 📒 Contact Book
### A desktop Contact Book application built with Python that provides a graphical user interface (GUI) with CustomTkinter(CTK) for managing contacts. The application allows users to perform Create, Read, Update, and Delete (CRUD) operations, making it easy to organize and maintain contact information.

# <br>✨ Features
- ***➕ Add new contacts***
- ***👀 View all saved contacts***
- ***✏️ Update existing contacts***
- ***🗑️ Delete contacts***
- ***🔍 Search contacts***
- ***🖥️ User-friendly graphical interface***
- ***💾 Store and manage contact information***

# <br>🛠️ Technologies Used
- ***Python 3***
- ***Tkinter (GUI)***
- ***CustomTkinter***
